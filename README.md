# Divide-and-Conquer Assignment

This project implements and compares two divide-and-conquer sorting algorithms in Python:

- Merge Sort
- Quick Sort

The algorithms are tested using:

- Sorted data
- Reverse-sorted data
- Random data

The program measures:

- Execution time
- Memory usage

Dataset sizes tested:

- 1,000 elements
- 5,000 elements
- 10,000 elements
